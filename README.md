# ⚡ EV Adoption Forecasting

This project uses historical electric vehicle registration data (from Washington State, USA) to forecast future EV adoption at the county level using a Random Forest Regressor model.

The trained model is deployed through a **Streamlit web app** that allows users to:

- Select a county and view a 3-year EV growth forecast
- Visualize historical + predicted EV trends on an interactive graph
- Compare forecasts across multiple counties
- Get percentage growth insights for planning infrastructure

The goal is to provide a data-driven tool to help planners, policymakers, and stakeholders make informed decisions on EV infrastructure.
